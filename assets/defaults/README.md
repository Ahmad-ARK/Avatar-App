# Bundled default assets

This is the deliberately small, offline-safe subset of the user's shared asset library that the current renderer can actually consume. `manifest.json` is the source of truth: it records stable IDs, tags, provenance, full duration, and the recommended source-in/source-out range.

The originals remain in the shared library. These copies are user-supplied sample-pack files; verify the original pack terms before redistributing an installer. Do not add installers, previews, `__MACOSX`, PDFs, or multi-gigabyte source packs here.
